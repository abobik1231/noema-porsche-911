# NOEMA: Porsche 911 Targa 4S

Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, локальный model-viewer.

```sh
npm install
npm run dev -- --port 5220
```

Проверки: `npm run lint`, `npm run typecheck`, `npm run build`.
Production: `npm run start -- --port 5220`.

Автомобиль и двигатель используют предоставленные пользователем GLB. Материал PAINT_COLOR_4 меняет весь окрашенный кузов. Камера автомобиля перемещается горизонтально от -95° до 95° вокруг передней части; прямой задний ракурс исключён. После отпускания мыши, пальца или клавиши камера плавно возвращается к исходному ракурсу. Ползунок меняет масштаб от 80% до 125%; масштаб сохраняется при возврате. Метки закреплены в координатах 3D-модели и скрываются на невидимой стороне. На мобильных экранах детали открываются нижней навигацией.

Двигатель вращается свободно, с наклоном, и возвращается к исходному ракурсу после отпускания. Он загружается при открытии раздела. В разделе прямо указано, что F6 Boxer Engine от Scuderia Morello является концептом и не штатным двигателем данного Porsche. Модель и обозначения MORELLO не изменены.

Колесо использует предоставленную модель Porsche Wheel. Вращение ограничено лицевой стороной (±65°), после отпускания восстанавливается исходное положение. Кнопок и ползунков у колеса нет.

Фото интерьера показывают Porsche 911 Targa 4S Heritage Design Edition; исполнение обозначено в интерфейсе. Источники: ASSETS.md.
